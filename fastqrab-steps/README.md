# fastqrab-steps

Internal support crate for [**fastqrab**](https://crates.io/crates/fastqrab), the
multi-tool of FASTQ (pre-)processing.

This crate implements the pipeline building blocks: the read transformations,
filters, reports, and demultiplexing steps that fastqrab composes into a
pipeline. It is not meant to be used on its own.

👉 **See the [`fastqrab` crate](https://crates.io/crates/fastqrab) for
documentation, installation, and usage.**

Full documentation lives at <https://tyberiusprime.github.io/fastqrab/>.
